# Grus QR

VRChatアバター「Grus」の社員証QRから開く、架空の人員照合端末です。黒と緑の認証画面が徐々に異常を示し、「対象は仮想存在です」と告げます。

## 使い方

ビルド・インストール不要。`index.html` をブラウザで開くだけで動きます。GitHub Pagesでもそのまま公開できます。外部通信や個人情報の取得はありません。

## 演出

- 読み取り → ID照合 → 実在性確認 → 異常表示 → 最後の問いかけ
- スマホ対応、走査線とカーソルの演出
- スキップと再照合ボタン
- OSの「視差効果を減らす」設定では全文を即時表示

## カスタマイズ

`index.html` 内の `sequence` でログの文章と各行の待機時間（ミリ秒）、`question` で最後の問いかけを変更できます。IDはカードとログの両方に記載しています。CSSの `:root` で文字色・補助色・罫線色を変更できます。

HTML / CSS / Vanilla JavaScriptのみの個人の遊びプロジェクトです。
